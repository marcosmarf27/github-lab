# Política de Segurança

Este é um repositório de estudo (laboratórios de Git/GitHub), mas segue aqui o processo recomendado para reportar problemas de segurança.

## Como reportar uma vulnerabilidade

**Não abra uma Issue pública** para relatar uma vulnerabilidade — isso divulga o problema (e possíveis formas de explorá-lo) antes de existir uma correção.

Use o **Private vulnerability reporting** do GitHub:

1. Vá em **Security** → **Report a vulnerability**, na aba do repositório.
2. Descreva o problema, o impacto e, se possível, os passos para reproduzir.

Isso abre uma conversa privada, visível apenas para os mantenedores do repositório, até que a correção seja publicada.

## O que esperar

Por ser um repositório de aprendizado, sem SLA formal de resposta. Ainda assim, todo relato será avaliado e, se procedente, corrigido antes de qualquer divulgação pública dos detalhes.
